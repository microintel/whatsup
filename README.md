What's Up

A modern real-time messaging web application built with Firebase Authentication, Firestore Database, and WebRTC voice calling.

Overview

What's Up is a responsive messaging platform developed by MicroIntel as a college project and learning demonstration. The application showcases real-time communication, cloud-based authentication, private messaging, typing indicators, message replies, and voice calling capabilities.

---

Features

Authentication

- Google Sign-In Authentication
- Secure user session management
- Logout functionality
- Account deletion support

Messaging

- Real-time private messaging
- Instant message delivery
- Message timestamps
- Reply to messages
- Delete individual messages
- Clear all personal messages
- Typing indicators
- User search functionality

Voice Calling

- Real-time voice calls using WebRTC
- Incoming call notifications
- Call accept/reject options
- Call status updates
- End call functionality

User Interface

- Modern dark theme design
- Responsive mobile-friendly layout
- Animated particle backgrounds
- Sidebar navigation
- Mobile drawer menu
- Toast notifications
- Smooth user experience
